# Lam Anh Tuan, portfolio

Personal introduction and portfolio page of Lam Anh Tuan, Senior Product Designer based in Ho Chi Minh City.

- Single static page: `index.html` (HTML, CSS and JavaScript in one file, no build step, no dependencies besides Google Fonts)
- Vietnamese and English versions, switchable from the header
- Light and dark theme follow the visitor's system setting
- Cursor animation that rebuilds the page as you scroll; it respects `prefers-reduced-motion`

## Run locally

Open `index.html` in a browser.

## Credit

The idea of a page rebuilt by a swarm of cursors comes from [Swarm](https://califa.github.io/swarm-site/) by Joel Califa. The animation code in this project is written from scratch.
